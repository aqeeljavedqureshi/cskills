# define-acceptance

1. Use confirmed requirements only.
2. Cover happy paths and material failure or permission cases.
3. Write concise Given/When/Then scenarios with observable outcomes.
4. Keep unresolved behavior under Open questions, not in scenarios.

Output: Gherkin scenarios; then Open questions if needed.
